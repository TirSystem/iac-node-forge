## Overall Verdict

Go — every Mandatory criterion passes. The live round trip of 2026-10-20 showed that treating a file already on the server as a failure made every restore onto a changed folder fail; the rule now fails a restore only on a missing or changed file and notes the files left in place. The row is accepted in autonomous mode.
