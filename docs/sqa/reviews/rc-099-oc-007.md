## Overall Verdict

Go - every Mandatory criterion passes. The row is accepted in autonomous mode. The contracts carry the rules of ADR-0009 that a test must show: nothing is changed on the server by a backup, a destination without room is refused before anything is copied, a changed byte is reported as failed, an unknown host key stops until accepted and a changed one is never accepted.
